# Frontend Mua hàng

Thư viện frontend đã được cài trong `../CongTyHuynhDuc_ERP_env/node_modules`
(tính từ **gốc repo**) và liên kết vào `node_modules` ở gốc repo. Xem
`README.md` ở gốc repo để biết cách chuẩn bị lại môi trường nếu chuyển máy.

Chạy từ thư mục này:

```powershell
npm run dev
```

Kiểm tra: `npm run lint` và `npm run build`. Không cần `npm install` riêng trong
module khi các dependency hiện tại vẫn tương thích với môi trường chung.
